# Doodle

A recursively zoomable creative document. Right now: an image workflow graph — Model → Prompt → Image Generator → Preview — on a field you can pan, zoom, wire and run, built on [The Soft Machine](https://github.com/x0bd/v00v).

Vite + React + TypeScript, Tauri 2. `pnpm install && pnpm tauri dev`. See `HANDOFF.md`.
